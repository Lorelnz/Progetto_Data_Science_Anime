This dataset containing general information and statistics for each anime released between 1956 and 2025. 

* anime_id: Unique identifier for each anime title (Primary Key).
* title: The official name of the anime.
* score: Average user rating on MyAnimeList (0-10).
* rank: Global ranking based on score.
* popularity: Ranking based on the number of members.
* members: Total number of users following the anime.
* synopsis: A brief plot summary of the anime.
* start_date: The date the anime first aired (ISO-8601).
* end_date: The date the anime finished airing (ISO-8601).
* type: Media format (TV, Movie, OVA, ONA, Special).
* episodes: Total number of episodes.
* image_url: Link to the official poster image.
